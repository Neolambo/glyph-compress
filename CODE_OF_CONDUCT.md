# Code of Conduct

GlyphCompress is a small, maintainer-driven open-source project. The expectations here are deliberately short.

## Expected Behavior

- Be respectful and direct in issues, pull requests, and discussions.
- Assume good faith; disagree with the argument, not the person.
- Give and accept constructive, specific technical feedback — this project's own contribution history is built on "found a real bug while testing X" style reports, which are always welcome.

## Unacceptable Behavior

- Harassment, personal attacks, discriminatory language, or unwelcome sexual attention.
- Sustained disruption of issues, pull requests, or discussions.
- Publishing others' private information without consent.

## Scope

This applies to all project spaces — GitHub issues, pull requests, discussions — and to any other setting where someone is representing the project.

## Enforcement

Report violations to `campiossasco1@gmail.com`. The maintainer will review and respond, and may edit, remove, or reject contributions and comments, or temporarily or permanently ban a contributor for behavior deemed inappropriate, threatening, offensive, or harmful.
