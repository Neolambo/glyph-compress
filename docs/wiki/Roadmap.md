# Roadmap

This page used to carry its own copy of the version history. That had three problems: it was a third copy of the same list (behind `ROADMAP.md`, and behind GitHub Releases), it went stale — it still announced `v1.33.2` as current while the project shipped `v1.36.0` — and a reader had no way to tell which of the three copies was authoritative.

So it no longer carries one.

- **What shipped, per version** → [GitHub Releases](https://github.com/Neolambo/glyph-compress/releases). This is the canonical changelog.
- **What is planned, and what was tried and rejected** → [`ROADMAP.md`](https://github.com/Neolambo/glyph-compress/blob/master/ROADMAP.md) in the repository, kept beside the code it describes.
- **Longer-form notes on individual releases** → [`RELEASE_NOTES.md`](https://github.com/Neolambo/glyph-compress/blob/master/RELEASE_NOTES.md).

`ROADMAP.md` also records **refuted** directions together with the measurement that killed them — IDF term weighting, content indexing in selection, colour and image encoding of glyphs, and the transport explanation for Gemini's codeword failure. Those entries exist so the same idea is not re-attempted on the same evidence, and they are worth as much as the list of what worked.
